# Gamuda AI Bootcamp lesson work

Personal examples and exercises assembled for trainer and JPSM review. This collection includes worked examples and saved classroom code. A separate folder contains work that still needs a result or more implementation.

| Folder | Material |
| --- | --- |
| [01 HTML](01-html/) | Browser practice including headings, lists, links and images |
| [02 CSS](02-css/) | CSS practice and external-stylesheet recipe card |
| [03 JavaScript](03-javascript/) | Variables, arrays, control flow, loops and functions |
| [04 React](04-react/) | First Vite project and classroom components |
| [05.5 FastAPI](05.5-fastapi-introduction/) | Root endpoint and book-search practice |
| [06.2 PostgreSQL Books](06.2-postgresql-books/) | Books CRUD |
| [06.3 FastAPI Part 2](06.3-fastapi-part-2/) | Response model, routers and basic authorization |
| [06.4 React and FastAPI](06.4-react-books/) | Books learning project and extracted BookManager exercise |
| [07-08 Gemini and LangChain](07-08-gemini-langchain/) | Sentiment, terminal history, webpage summary and the adapted image API |
| [09.2 MongoDB RAG](09.2-mongodb-rag/) | Text index, ingestion and retrieval samples |
| [09.3 AI agent tools](09.3-ai-agent-tools/) | Compound interest, web search, currency and tracing setup |
| [09.4 Agent memory](09.4-ai-agent-memory/) | In-memory and PostgreSQL checkpoint examples |
| [09.5 MCP](09.5-mcp-local-tools/) | Confirmed dice and random-number demos |
| [10.4 YOLO](10.4-yolo-training/) | COCO8 training script and 10-epoch output |
| [Saved work in progress](in-progress/) | Incomplete or unverified attempts |

Run examples from their own folders. Use the configuration templates with your own private values. Extensionless HTML practice copies gained an .html extension for the browser. The two search/currency copies omit their unused eval calculator, and the auth demo copies read tokens from the environment. The original exercise files are in their original folders.
